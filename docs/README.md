# Ask user guides

Use these guides to install, configure, use, and troubleshoot Ask.

## Start here

1. Follow the setup guide to create a Discord application and start Ask.
2. Read the command guide to learn slash commands and message triggers.
3. Read the configuration guide to check credentials, Discord access, and locales.
4. Read the deployment guide to run Ask in Docker.
5. Use the troubleshooting guide when Ask does not start or answer a request.
